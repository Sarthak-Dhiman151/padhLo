# Contributing

## What We Look For

We actively welcome contributions that provide lasting, high-utility value to Indian students:

- **Official Portals**: Verified governmental, state council, or statutory examination URLs (`.gov.in`, `.nic.in`, `.ac.in`).
- **Free & Open Access Learning**: Peer-reviewed textbooks, open courseware, public datasets, open-source software, and non-profit educational platforms.
- **Accurate Descriptions**: Concise, objective summaries explaining what the resource offers, eligibility criteria, and any limitations.
- **Dead Link Reports**: Notifications regarding broken URLs, moved government portals, or outdated syllabus documents.

## What We Do NOT Accept

To maintain high standards of academic credibility and safety, we strictly reject:

- Commercial coaching affiliate links or referral tracking codes.
- Pirated copyrighted material, paid course torrents, or unauthorized book re-uploads.
- Unverified WhatsApp / Telegram group links or unvetted private channels.
- Phishing sites, paid job guarantee schemes, or paid exam-paper leak scams.
- Ad-heavy blog posts that merely scrape and repost official government notices.

## How to Suggest Changes

### Option 1: Open a GitHub Issue (Quickest)
1. Visit our [GitHub Repository](https://github.com/).
2. Navigate to the **Issues** tab and click **New Issue**.
3. Use the format below:
   ```markdown
   **Resource Name**: Name of the website or portal
   **URL**: https://example.gov.in/
   **Category**: e.g., Entrance Exams > Engineering, or School Resources > CBSE
   **Description**: 1-2 sentence factual explanation of what the resource provides.
   **Verification Note**: How did you verify this is official or legally free?
   ```

### Option 2: Submit a Pull Request (Direct Markdown Edit)
1. Fork the PadhLo repository on GitHub.
2. Navigate to `src/content/topics/` or `src/content/pages/` and locate the relevant `.md` file.
3. Edit the markdown file following our standard link syntax:
   `- [Resource Title](https://example.gov.in/) - Concise factual description.`
4. Ensure your changes compile cleanly.
5. Submit a Pull Request with a clear summary of what you added or corrected.

## Link Formatting Guidelines

- **Use Secure Protocols**: Always provide `https://` URLs rather than unencrypted `http://`.
- **Prefer Canonical Links**: Link directly to the official homepage or canonical resource repository, avoiding intermediate URL shorteners (`bit.ly`, `tinyurl`).
- **Include Subject Code & Session**: When linking specific board papers or exam bulletins, state the class, subject code, and academic year clearly in the description.
